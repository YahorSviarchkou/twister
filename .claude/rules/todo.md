# Open questions as TODOs

- When something is unclear during a task (an ambiguity, a doubt, a decision only the owner can make), put a TODO at that exact place right away, so it is not forgotten:
  - `// TODO(tw-<issue>): …` when it belongs to an existing GitHub issue;
  - `// TODO(discuss): …` when there is no issue for it yet.
  Use the file's comment syntax outside Java.
- Do not use TODOs for work you can finish in the current task.
- At the end of the task, list every TODO you added (file and line) in the summary and propose an issue title for each `TODO(discuss)`.
