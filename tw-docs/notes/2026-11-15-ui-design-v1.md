# UI design v1

The first full UI design for the desktop app, made in Claude Design on 2026-11-15. The live canvas is the source of truth for visuals: [open the design](https://claude.ai/artifact/AJTesZt4JMRCbm2r5AYeK7). Exported sources are kept in [artifacts](../artifacts/2026-11-15-ui-design-v1/README.md).

## Key decisions

- **Fonts:** IBM Plex Sans for UI text, IBM Plex Sans Condensed for table headers, IBM Plex Mono for all numbers, money, dates and IDs. JavaFX has no OpenType `tnum`, so digits use a separate monospace family.
- **Colour:** petrol accent `#136B6E` (dark theme `#3AA5A4`), neutrals with a blue-green tint, dark petrol side navigation in both themes.
- **Tokens** are named as JavaFX looked-up colours: `-tw-bg`, `-tw-surface`, `-tw-accent` and so on. The dark theme is a `.dark` class on the scene root.
- **Statuses:** seven colour families (neutral, blue, violet, amber, green, graphite, red) shared by order, task and work item. A status is always colour + icon + text.
- **Order board columns:** New / Diagnosis / In progress / Waiting for payment / Closed today. "Accepted" is split by task status, otherwise one column would hold the whole workshop. Rejected orders are behind a filter.
- **"No repair needed":** task becomes "Ready · no repair", order goes to "Waiting for payment", the invoice covers diagnosis only.
- **Plugin slots:** `nav.item`, `order.tab`, `toolbar.action`, `context.action`, `dashboard.block`, `statusbar.item`. In the design they are drawn as dashed orange frames; in the product the plugin renders its own elements with the same components.
- **Grid:** 4/8. Radii 3 (chips), 4 (controls, cards), 6 (popovers, dialogs). Control heights 28/32/40. Side menu 232 / 56 collapsed. Top bar 52.

## Notes for implementation

The design targets JavaFX 21 + CSS: layouts map to `BorderPane`, `SplitPane`, `TabPane`, `TableView`; shadows use `dropshadow(gaussian, …)`; no blur. Fonts ship with the app as TTF (OFL, with Cyrillic).

If the web UI is chosen for the front desk (see [extension architecture](2026-11-15-extension-architecture.md)), the same tokens and components carry over almost unchanged.
