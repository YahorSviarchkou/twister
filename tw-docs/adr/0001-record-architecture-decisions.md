# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-21
- **Deciders:** project owner

## Context

The project is being restructured from a monolithic JavaFX app into modules. Many decisions were discussed in chats and on whiteboards, and the reasoning gets lost between sessions, both for people and for coding agents.

## Decision

We will record significant architecture and product decisions as ADRs in `tw-docs/adr/`, using the template in `0000-template.md`. Notes may propose; only an accepted ADR states a decision.

## Consequences

- Agents and contributors can check `tw-docs/adr/` before changing architecture.
- A decision that is not in an ADR is still open.
